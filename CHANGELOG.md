# CHANGELOG

Todas as mudanças notáveis neste projeto serão documentadas aqui.

## [2.0.0] - 2026-08-24

### ✨ Novo

- **Mobile First**: Interface 100% otimizada para celular
- **Mia IA**: Assistente que processa transações em linguagem natural
- **TikTok Shop Automático**: Renda semanal toda quarta-feira
- **Dashboard**: Visão completa de saldo, entradas e saídas
- **Settings**: Página de configurações com backup/export
- **Transações Automáticas**: Digite e Mia categoriza sozinha
- **Histórico Completo**: Filtro por tipo de transação
- **Tema Verde Oliva**: Design minimalista e profissional
- **Zustand State**: Gerenciamento de estado robusto
- **TypeScript**: Type-safe em toda aplicação
- **Tailwind CSS**: Styling mobile-first
- **Vercel Ready**: Pronto para deploy em produção
- **API da IA**: Endpoint `/api/mia` para processar transações
- **LocalStorage**: Dados persistem no navegador
- **Export JSON**: Backup de todos os dados

### 🎨 Design

- Paleta de cores: Branco + Verde Oliva
- Componentes reutilizáveis e bem estruturados
- Animações suaves e feedback visual
- UX extrema com focus em usabilidade

### 🔧 Técnico

- Next.js 14 + React 18 + TypeScript
- Zustand para state management
- Antropic Claude API integration
- 20+ funções utilitárias
- Error handling robusto
- Validação de dados
